## 개요

영상과 이미지 속 개인정보를 AI로 가려 주는 서비스의 소개 사이트입니다. 서비스를 처음 접한 사람이 스크롤을 내리면서 기능을 차례로 이해하도록 구성했고, 여러 언어로 볼 수 있게 했습니다. 페이지 구현을 맡았습니다.

## 한 일

Vue 3와 TypeScript로 페이지를 만들고, 반응형 레이아웃은 Tailwind CSS로 잡았습니다. 스크롤 위치에 맞춰 설명이 나타나는 애니메이션은 GSAP으로 구현했습니다. 문구는 언어별 파일로 빼서, 언어를 바꿔도 구성은 그대로 보이게 했습니다.

## 배운 점

소개 사이트에 들어오는 사람은 이 서비스를 모릅니다. 기능을 한꺼번에 늘어놓지 않고 스크롤 순서대로 하나씩 보여 주니, 페이지 구조가 곧 설명 순서가 됐습니다.

## AI를 대하는 태도

반복되는 마크업이나 애니메이션 값을 맞추는 일은 AI에게 맡깁니다. 다만 결과는 직접 스크롤해 보면서, 처음 온 사람이 이 순서로 이해할 수 있을지 봅니다.
