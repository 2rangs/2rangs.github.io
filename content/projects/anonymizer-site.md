## 개요

영상과 이미지 속 개인정보를 AI로 가리는 비식별화 서비스를 소개하는 웹사이트입니다. 서비스를 처음 보는 사람이 스크롤을 따라 내려가며 기능을 이해하도록 구성했고, 세 개 언어로 제공했습니다.

## 한 일

- Vue 3와 TypeScript 기반 웹페이지 개발
- Tailwind CSS 기반 반응형 UI
- GSAP과 ScrollTrigger를 이용한 스크롤 애니메이션
- 한국어·영어·일본어 다국어 지원
