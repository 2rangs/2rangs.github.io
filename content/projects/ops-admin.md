## 개요

AI 탐지 장비와 그 장비에서 돌아가는 모델을 운영하는 관리자용 시스템입니다. 장비 관리, 장비 상태 확인, 모델별 탐지 정책 변경과 변경 이력 조회를 한 곳에서 합니다. 화면 개발에 더해 타입·테스트 기준과 배포까지 혼자 맡았습니다.

## 정책 관리와 장비 모니터링

모델별 탐지 정책을 설정하는 화면을 만들었습니다. 정책 화면을 모델 목록에 맞춰 구성하도록 바꿔서, 탐지 대상과 모델이 늘어나도 화면을 새로 만들 필요가 없게 했습니다.

장비 화면에서는 장비별 상태와 운행 정보를 보여 주고, 여러 조건을 조합해 걸러 볼 수 있게 했습니다. 장비 상세에서 탐지 결과로 이어지고, 탐지 결과 화면에서는 이미지 위에 탐지 영역과 관심 영역을 표시하고 설정할 수 있습니다.

정책과 설정은 변경 이력을 남기고, 이전 값과 비교해 바뀐 부분만 강조해 보여 줍니다. 정책을 바꾸면 장비가 찾아내는 결과도 달라져서, 무엇이 언제 바뀌었는지 되짚을 수 있어야 했습니다.

## 타입 정리

API 응답이 들쑥날쑥해서 코드 곳곳에 타입이 비어 있었고, 데이터 모양이 바뀌면 화면이 어디서 깨질지 알 수 없었습니다. 기능을 더 얹기 전에 응답과 화면 데이터에 타입을 정의해 빈자리를 채우고, 엄격한 타입 검사를 켰습니다. 예외 처리도 이때 정리했고, 린트와 테스트도 붙였습니다.

## 배포 자동화

손으로 하던 배포는 단계를 빠뜨리기 쉽고, 문제가 생기면 되돌리기도 어려웠습니다. GitHub Actions로 자동 배포를 만들고, 배포가 잘못되면 이전 버전으로 돌아갈 수 있게 했습니다.

## 배운 점

타입을 정리하는 동안은 기능이 하나도 늘지 않아 더뎌 보였습니다. 그래도 데이터 모양을 모르는 채로 기능을 얹는 것보다는 낫다고 봤습니다.

배포도 같았습니다. 되돌릴 수 있다는 게 확실해야 운영 배포를 부담 없이 할 수 있었습니다.

## AI를 대하는 태도

PR을 올리면 Claude API와 GitHub Actions로 만든 리뷰 에이전트가 보안과 접근성부터 봅니다. 지적이 나와도 다 고치지는 않습니다. 운영자가 이 화면을 실제로 어떻게 쓰는지 생각해 보고 고칠 것만 고칩니다.
