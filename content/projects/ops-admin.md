## 개요

AI 탐지 장비와 서비스를 운영하는 관리자 시스템입니다. 고객사와 장비를 관리하고, 단말기 상태를 모니터링하고, 장비에서 돌아가는 AI 모델의 정책을 바꾸는 일을 한 화면 체계 안에서 할 수 있게 만들었습니다. 프론트엔드를 주도했고, 인증과 배포까지 맡았습니다.

## 목표

- 데이터를 많이 보여 주기보다 운영자가 빠르게 판단하게 만들기
- 상태 요약, 알림, 목록, 상세의 우선순위 정리
- 로딩, 빈 상태, 오류 상태까지 경험으로 설계

## 한 일

### 운영과 모니터링

- 고객사와 장비 관리
- 단말기 운행·통신 상태 모니터링

### AI 모델 정책

- AI 모델별 탐지 정책, 추론 모델과 임계값 관리
- 이미지 ROI(관심 영역) 설정과 편집
- 변경 이력 조회와 차이점 시각화

### 보안

- MFA 기반 인증
- HttpOnly 쿠키 인증 방식 적용

### 품질과 배포

- TypeScript 엄격화와 자동화 테스트
- GitHub Actions 기반 배포
- 배포 전 백업과 운영 장애 대응

## 배운 점

- 정보 구조 설계가 UI의 절반이다.
- 보여 주는 화면과 실제로 쓰이는 화면은 다르다.
- 실시간으로 바뀌는 데이터일수록 안정감 있게 표현해야 한다.
