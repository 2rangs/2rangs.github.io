## 개요

도로 현장 작업자가 쓰는 앱에서 인증·보안 기능과 현장 등록 기능을 맡았습니다. 전체 구조를 설계한 프로젝트가 아니라, 배분받은 기능을 보안 요구사항에 맞춰 구현한 작업입니다.

## 로그인 보안 강화

기존 로그인에 추가 인증 단계를 더했습니다. 단계에 따라 화면 상태를 바꾸고, 인증에 실패하거나 만료되는 경우를 처리했습니다. 로그인부터 재인증까지를 한 흐름으로 묶어서, 인증 상태와 화면·기능 접근 권한이 어긋나지 않게 했습니다. 단계마다 사용자가 지금 무엇을 해야 하는지 화면에서 안내하는 것도 따로 챙겼습니다.

보안 요구사항에 맞춰 통신 보호도 적용했고, 인증과 함께 정상 동작하는지 검증했습니다. 운영 환경에 따라 달라지는 부분은 환경별로 대응했습니다.

## 현장 등록

현장 등록 화면을 만들어 입력값을 검증하고 서버와 연동했습니다. 현장 작업 중에 생길 수 있는 예외도 처리했습니다.

## 배운 점

이미 돌아가는 시스템에 기능을 더하는 작업이라, 새 코드를 쓰는 시간보다 기존 인증 흐름을 이해하는 시간이 더 길었습니다. 인증 단계가 늘어날수록 사용자가 어디서 막히는지가 중요해져서, 보안 기능도 화면 안내까지 갖춰야 끝난 일이었습니다.

## AI를 대하는 태도

맡은 티켓은 Jira와 Claude를 연결해 정리를 맡깁니다. 보안 요구사항을 해석하거나 코드를 짤 때도 AI의 도움을 받지만, 인증처럼 틀리면 안 되는 부분은 요구사항 원문과 실제 동작을 직접 대조합니다. 판단이 갈리는 곳에서는 왜 그렇게 해야 하는지 AI에게도 묻고 저도 따져 본 뒤에 정합니다.
