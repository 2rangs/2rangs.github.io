## 개요

도로 현장 작업자가 쓰는 앱에서 인증·보안과 현장 등록 기능을 맡았습니다. 전체 프론트엔드 구조를 설계한 프로젝트는 아니고, 배분받은 기능을 구현하면서 보안 요구사항에 맞춰 대응한 프로젝트입니다. 서비스는 NCP와 AWS 환경에서 돌아가고, CSAP(클라우드 보안 인증) 관련 요구사항을 따라야 했습니다.

## MFA 인증과 세션

기존 단일 인증 방식에 다중 인증 단계를 더한 로그인 흐름을 만들었습니다. MFA 등록과 검증 단계에 따라 화면 상태를 바꾸고, 인증 실패와 인증 만료 같은 예외를 처리했습니다.

인증 토큰과 세션 수명을 관리하고, 세션이 만료되면 재인증으로 이어지게 했습니다. 인증에 실패하면 사용자 상태를 초기화합니다. 이 과정에서 가장 신경 쓴 것은 인증 상태와 실제 화면 접근 권한이 어긋나지 않게 하는 일이었습니다. 로그인, 추가 인증, 세션 만료를 각각의 기능이 아니라 하나의 흐름으로 보고, 화면·기능 접근을 인증 상태에 맞춰 처리했습니다. 보안 기준을 지키는 것과 별도로, 각 단계에서 사용자가 지금 무엇을 해야 하는지 헷갈리지 않게 안내하는 일도 따로 필요했습니다.

## 요청 암호화

보안 요구사항에 맞춰 API 요청에 RSA-OAEP 기반 암호화를 적용했습니다. 암호화를 넣으면서 요청 데이터 처리에서 생기는 문제를 검토했고, 인증과 암호화가 함께 정상 동작하는지 검증했습니다.

## 현장 등록

현장 등록 화면을 만들어 입력값을 검증하고, 등록 데이터를 서버 API와 연동했습니다. 현장 작업 중에 생기는 예외도 처리했습니다.

## 클라우드 환경과 보안 기준

NCP와 AWS의 환경 차이에 맞춰 요청과 설정을 따로 대응했고, 인증·통신 환경에 따라 생기는 문제를 분석했습니다. CSAP 관련 보안 요구사항에 맞춰 인증·요청·세션 전반을 구현하고 검토했습니다. 요구사항에 맞춰 대응한 것이고, 인증 자체를 취득한 것은 아닙니다.

이미 돌아가는 시스템에 기능을 더하는 작업이라, 새 코드를 쓰는 시간보다 기존 인증 흐름을 이해하는 시간이 더 길었습니다.
