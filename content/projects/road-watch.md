## 개요

도로 위의 위험물을 관제하는 시스템에서 배분받은 프론트엔드 기능을 구현하고 기존 화면을 개선했습니다. 프로젝트 전체를 맡은 것은 아니며, 인증과 보안, 현장 관리 기능을 중심으로 참여했습니다.

## 한 일

### 인증과 보안

- MFA 인증과 세션 관리
- RSA-OAEP 암호화 처리

### 기능

- 현장 등록·관리 기능
- 멀티 클라우드 운영 환경 대응

### 유지보수

- API 연동과 오류 처리
- 기존 화면 유지보수

## 배운 점

- 인증과 폼은 기능이 아니라 흐름이다. 로그인, 추가 인증, 세션 만료가 하나의 경험으로 이어져야 한다.
- 보안 기준을 지키면서도 사용자가 헷갈리지 않게 안내하는 일이 따로 필요하다.
