## 개요

도로 위의 위험물을 관제하는 시스템에서 배분받은 프론트엔드 기능을 구현하고 기존 화면을 개선했습니다. 프로젝트 전체를 맡은 것은 아니며, 인증과 보안, 현장 관리 기능을 중심으로 참여했습니다.

## 맡은 범위

| 영역 | 내용 |
|---|---|
| 인증 | MFA 인증, 세션 관리 |
| 보안 | RSA-OAEP 암호화 처리 |
| 기능 | 현장 등록·관리, 멀티 클라우드 운영 환경 대응 |
| 유지보수 | API 연동, 오류 처리, 기존 화면 개선 |

## 한 일

### 인증과 보안

- MFA 인증과 세션 관리
- 민감한 값을 서버로 보내기 전에 브라우저에서 RSA-OAEP로 암호화

로그인, 추가 인증, 세션 만료는 각각 따로 만들면 사용자가 지금 어느 단계에 있는지 헷갈립니다. 세 단계를 하나의 흐름으로 보고, 세션이 끝났을 때 어디로 돌아가고 무엇을 다시 입력해야 하는지가 분명하게 보이도록 다듬었습니다.

### 현장 관리

- 현장 등록·수정·관리 기능
- 여러 클라우드 환경에서 같은 화면이 동작하도록 환경별 설정 대응

### 유지보수

- API 연동과 오류 처리
- 기존 화면 유지보수와 개선

## 배운 점

- 인증과 폼은 기능이 아니라 흐름이다. 로그인, 추가 인증, 세션 만료가 하나의 경험으로 이어져야 한다.
- 보안 기준을 지키면서도 사용자가 헷갈리지 않게 안내하는 일이 따로 필요하다.
- 이미 돌아가는 시스템에 기능을 더할 때는, 새 코드보다 기존 흐름을 먼저 이해하는 시간이 더 길다.
