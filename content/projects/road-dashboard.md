## 개요

한 지자체 도로에서 AI가 찾아낸 위험물 탐지 현황을 보여 주는 관제 대시보드입니다. 탐지 건수와 유형별 통계, 위험물이 발견된 위치, 새로 들어온 탐지 알림을 따로 찾아보지 않고 한 화면에서 확인하도록 만드는 것이 목표였습니다.

## 한 일

### 탐지 현황 대시보드

- AI 도로 위험물 탐지 데이터를 시각화하는 대시보드
- 탐지 건수와 유형별 통계
- 위험물 데이터와 위치 정보를 연결한 지도 시각화
- 탐지 현황과 통계를 한 화면에서 보도록 구성하고, 정보의 중요도에 따라 레이아웃 배치

### 차트와 통계

- ApexCharts로 탐지 데이터 차트 구성
- 탐지 유형과 기간에 따른 통계 표현
- 서버 데이터를 차트에 맞는 형태로 가공
- 통계 수치가 바뀌면 차트 데이터 갱신
- 화면 크기에 따라 차트 영역과 레이아웃 대응

### 실시간 알림

- Pusher로 신규 탐지 이벤트 수신
- 새 탐지가 들어오면 대시보드 정보 갱신
- 실시간으로 들어온 데이터와 기존에 조회한 데이터 연동
- 탐지 이벤트에 따른 사용자 알림 표시

### 지도와 커버리지

- 위험물 탐지 위치를 지도에 표시
- 데이터의 지리적 분포와 탐지 커버리지 시각화
- 지도와 통계를 함께 볼 수 있는 화면 구성

## 직접 내린 결정

| 문제 | 선택 |
|---|---|
| 복잡한 탐지 데이터 | 통계와 차트 중심으로 정보 구조화 |
| 새 탐지 발생 | Pusher 기반 실시간 이벤트 처리 |
| 지리적 분포 파악 | 지도와 통계 데이터 연계 |
| 대시보드 가독성 | 중요도에 따른 정보 배치 |
| 다양한 화면 크기 | 반응형 레이아웃과 차트 대응 |

## 배운 점

- 대시보드는 데이터를 많이 보여 주는 화면이 아니라, 무엇을 먼저 봐야 하는지 알려 주는 화면이다.
- 실시간 데이터는 이미 보고 있던 데이터와 자연스럽게 합쳐져야 한다.
