## 개요

도로 위험 분석 서비스에서 분석 데이터를 조회하는 화면과 대량 데이터 조회 성능 개선을 맡았습니다. 기능 단위로 참여했습니다.

## 한 일

### 조회 화면

- 분석 데이터 조회와 필터링
- 분석 결과 시각화 개선

### 성능

- 대량 데이터 조회 최적화: 한 번에 받던 요청을 나눠 보내고 병렬로 조회하도록 개선

### 수정과 문서

- 지도·이미지 기반 Bounding Box 오류 수정
- 기능 문서화

## 배운 점

- 데이터가 많아질수록 화면보다 요청 방식이 먼저 병목이 된다.
