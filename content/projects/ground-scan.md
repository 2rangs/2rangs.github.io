## 개요

도로 아래 지반 침하 위험을 분석하는 서비스에서, 맡은 프론트엔드 기능의 구현과 성능 개선, 오류 수정을 맡았습니다. 전체 구조를 설계한 프로젝트는 아닙니다.

## 데이터 조회와 필터링

분석 데이터가 많아지면서 한 번에 전부 받아 오는 방식이 느려졌습니다. 조회를 여러 단위로 나눠 병렬로 받고, 돌아온 응답을 합쳐 화면에 그리도록 바꿨습니다. 요청이 여러 개 오가는 동안 응답 순서가 바뀌거나 일부가 실패하는 경우도 처리했습니다.

조건별 필터도 만들어서, 조건을 바꾸면 결과가 바로 갱신되게 했습니다.

## 이미지 편집 기능 수정

이미지 위에서 영역을 편집하는 기능에 오류가 있었습니다. 저장된 좌표와 화면에 보이는 위치가 어긋나는 부분을 찾아 고치고, 편집 중에 생기는 예외 처리도 보강했습니다. 남이 만든 구조 안에서 고치는 작업이라 변경 범위를 좁게 잡고 필요한 부분만 손댔습니다.

## 문서화

기존 기능과 데이터 처리 구조를 분석한 내용, 오류의 원인과 수정 내용을 유지보수용 문서로 남겼습니다. 적어 두지 않으면 다음 사람이 같은 오류를 처음부터 다시 파야 합니다.

## 배운 점

남의 코드는 덜 건드릴수록 안전했습니다. 원인을 정확히 짚을수록 고칠 곳이 줄었고, 다른 기능을 깨뜨릴 걱정도 줄었습니다.

## AI를 대하는 태도

처음 보는 코드는 AI에게 구조부터 요약해 달라고 합니다. 요약은 어디부터 읽을지 정하는 데만 쓰고, 실제 동작은 코드와 화면을 직접 보며 확인합니다.
