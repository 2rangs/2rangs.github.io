## 개요

도로 아래 지반 침하(싱크홀) 위험을 분석하는 서비스에서, 전체 구조 설계보다는 배분받은 프론트엔드 기능의 구현과 성능 개선, 오류 수정을 맡았습니다. 맡은 영역은 대량 데이터 조회, 조건별 필터링, Bounding Box 편집기, 기술 문서화였습니다.

## 대량 데이터 조회

분석 데이터가 많아지면서, 많은 데이터를 한 번의 요청으로 받아 오는 방식이 화면보다 먼저 병목이 됐습니다. 그래서 조회 요청을 여러 단위로 나누고, 나눈 요청을 병렬로 보내는 비동기 조회로 바꿨습니다. 돌아온 응답들은 하나로 합쳐 화면에 표시하고, 여러 요청이 오가는 동안의 응답 흐름과 일부 요청이 실패하는 경우도 처리했습니다.

## 분석 데이터 필터링

조건별 필터링 기능을 만들고, 필터 조건이 바뀌면 조회 데이터가 갱신되게 했습니다. 이 과정에서 조회와 필터 처리 로직을 정리했고, RSA 관련 분석과 기능 구현도 맡았습니다.

## Bounding Box 편집기

이미지 위에서 Bounding Box를 편집하는 기능에 오류가 있어 원인을 분석했습니다. 좌표 데이터와 실제 화면 표시가 어긋나는 부분을 점검해 좌표와 편집 상태에 관한 문제를 고쳤고, 편집 중에 생기는 예외 처리도 보강했습니다.

남이 만든 구조 안에서 고치는 작업이라, 구조를 크게 바꾸기보다 변경 범위를 좁게 정해 필요한 부분만 수정했습니다.

## 문서화

기존 기능과 데이터 처리 구조를 분석한 내용, 오류 원인과 수정 내용을 유지보수용 기술 문서로 남겼습니다. 고친 이유를 적어 두지 않으면 같은 오류를 다음 사람이 처음부터 다시 분석해야 하기 때문입니다.
