## 개요

좋아하는 게임 데이터로 UI와 인터랙션을 실험해 보려고 만든 포켓몬 도감과 팀 빌더입니다. 재미로 시작했지만, 결국 사용자가 많은 데이터를 더 쉽게 탐색하게 만드는 과정이었습니다.

## 목표

- 관심 있는 게임 데이터를 활용한 인터랙션 설계 실험
- 필터, 조합 계산, 팀 구성 기능
- 사용자가 탐색하는 경험 중심의 UI

## 한 일

- React, Vite, Tailwind CSS, TanStack Query 기반 도감과 팀 빌더
- 데이터 요청과 캐시는 TanStack Query로 관리
- Lazy Loading 구현
- GitHub Pages 배포

## 배운 점

- 데이터 구조 설계가 인터랙션의 시작이다.
- 재미있는 탐색 경험도 UX다.
- 사이드 프로젝트는 실험하기 좋은 공간이다.
